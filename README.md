# Análise de Redes de Sensores utilizando Grafos

## Sobre o projeto

O projeto consiste na implementação de um programa em linguagem C para representar e analisar uma rede de sensores utilizando grafos não direcionados e ponderados.

O objetivo é aplicar conceitos de estruturas de dados, teoria dos grafos e algoritmos na análise da conectividade e da resistência de uma rede a falhas.

## Funcionalidades

- Carregamento de grafos a partir de arquivos de texto.
- Representação de grafos por listas de adjacência.
- Busca em largura (BFS).
- Busca em profundidade (DFS).
- Identificação do caminho com menor número de saltos.
- Verificação da conectividade da rede.
- Identificação da existência de pontos de articulação e pontes.
- Cálculo do grau médio e do coeficiente de agrupamento (Clustering).
- Análise da resistência da rede a falhas.
- Remoção de sensores.

## Conceitos abordados

- Estruturas de dados.
- Teoria dos grafos.
- Listas encadeadas.
- Ponteiros e alocação dinâmica de memória.
- Algoritmos de busca.
- Manipulação de arquivos.

**Linguagem utilizada:** C.
